# evil-teddy-ltd/homebrew-tap

Homebrew formulae for Evil Teddy tools.

```sh
brew tap evil-teddy-ltd/tap
brew trust evil-teddy-ltd/tap
brew install operatord
```

| Formula | What it is |
|---|---|
| `operatord` | The [Switchboard](https://evil-teddy.com/switchboard) host daemon and `operator` CLI. Set-up steps print after install. |

`operatord` installs one self-contained executable for your platform (macOS and Linux, Apple Silicon/arm64 and
Intel/x64) from this repository's [releases](https://github.com/evil-teddy-ltd/homebrew-tap/releases). It needs
nothing else from Homebrew.
